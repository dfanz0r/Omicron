## Remaining Direct Cleanup

### Finding A: `RefreshMetadataAsync` XML docs are now inaccurate

**Severity:** Low / direct cleanup  
**File:** `Omicron.Core/Models/ModelCatalogService.cs`

The method XML doc still says:

```csharp
/// Never throws — returns the count of metadata entries loaded.
```

This is no longer accurate because:

1. It intentionally rethrows cancellation.
2. If all sources return empty, it preserves previous metadata and returns the previous metadata count, not newly loaded count.

Suggested wording:

```csharp
/// Refresh layered metadata from the given sources.
/// Earlier sources provide baseline; later sources override for non-null fields.
/// Source failures are skipped, but caller cancellation is propagated.
/// If no source returns metadata, preserves the previous metadata snapshot.
/// Returns the active metadata count after refresh/preservation.
```

No code behavior issue; documentation-only.
