## New Review Findings

### Finding A: Malformed XML doc comment in `ModelMetadataSource.cs`

**Severity:** Low / direct fix  
**File:** `Omicron.Core/Models/ModelMetadataSource.cs`

There is a stray incomplete XML doc comment immediately before `IModelMetadataSource`:

```csharp
/// <summary>
public interface IModelMetadataSource
```

The project still builds because XML documentation warnings are not being emitted, but the comment is malformed and should be fixed immediately.

Recommended fix:

```csharp
/// <summary>
/// Provides model metadata from an external or internal source.
/// </summary>
public interface IModelMetadataSource
```

Also consider placing `IModelMetadataSource` before `IProviderModelMetadataSource` for readability, since the provider interface derives from it.

### Finding B: Failed metadata refresh can clear previously loaded metadata

**Severity:** Medium  
**File:** `Omicron.Core/Models/ModelCatalogService.cs`

`RefreshMetadataAsync` skips failing sources, merges whatever remains, then replaces `_metadata` even if every source failed or produced no entries:

```csharp
var merged = _merger.Merge(inputs.ToArray());
...
Interlocked.Exchange(ref _metadata, newDict);
return merged.Count;
```

This means a temporary external-source failure can wipe previously loaded metadata if no source succeeds during that refresh.

This may be intended for an explicit full refresh, but the current comments say sources should fail closed and never throw. For a metadata cache, preserving the last known-good data is usually safer.

Recommended options:

1. Preserve previous metadata when all sources fail and there are existing entries.
2. Add a separate `ClearMetadata()` or `RefreshMetadataAsync(..., clearOnEmpty: true)` option for explicit clearing.
3. Document that `RefreshMetadataAsync` is a full replacement operation and add a test covering the replacement semantics.

### Finding C: `ModelsDevMetadataSource` test does not verify `LoadAsync`

**Severity:** Low / direct test improvement  
**File:** `Omicron.Core.Tests/ModelMetadataTests.cs`

`ModelsDevSource_ReturnsEmpty` currently verifies only the source name:

```csharp
var source = new ModelsDevMetadataSource();
Assert.Equal("models.dev", source.Name);
```

The skeleton contract says it returns empty and should fail closed. Add an async assertion:

```csharp
var result = await source.LoadAsync();
Assert.Empty(result);
```
