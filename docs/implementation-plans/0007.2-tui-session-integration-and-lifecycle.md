# Implementation Plan 0007.2: TUI Session Integration and Lifecycle

**Status:** Proposed  
**Target:** Wire the TUI (`--tui`) to the full agent session lifecycle: model selection, API key resolution, session creation, streaming chat, and clean exit.  
**Depends on:** Plan 0007 (terminal backend), Plan 0007.1 (transcript viewport), Plans 0001–0003 (core architecture, providers, persistence)  
**Estimated Effort:** 2–3 days  

---

## Purpose

Plans 7 and 7.1 built a complete terminal rendering stack and transcript viewport. However, the `--tui` CLI flag currently launches `TuiMode.RunAsync(session: null)`, which shows only static welcome text with no agent backend connection. The full `AppLayout` (streaming responses, transcript scrollback, input editor, tool calls) is unreachable from the command line.

This plan makes `--tui` a first-class entry point that creates or resumes an `AgentSession`, launches the `AppLayout`, and cleanly exits back to the console on completion.

## Current State

`Omicron.CLI/Program.cs` currently does:

```csharp
// Line ~10
if (args.Contains("--tui"))
{
    await TuiMode.RunAsync(); // ← session = null, static fallback
    return;
}
// ... 200+ lines of console session setup follow
```

The console path creates an `OmicronHost`, discovers models, resolves API keys, creates `AgentSession`, and runs `ChatLoop`. The TUI path bypasses all of this.

`TuiMode.RunAsync(AgentSession? session)` has two branches:
- `session != null` → `AppLayout` with full chat
- `session == null` → static welcome text fallback

**File:** `Omicron.CLI/Program.cs`

### D5: `TuiSessionController.RunAsync` — main TUI entry

```csharp
public async Task RunAsync()
{
    using var backend = new SystemTerminalBackend();
    backend.Initialize();
    using var shell = new TuiShell(backend);

    // Try to find a usable model
    var availableModels = GetAvailableModels(_catalog, _cfg);
    AgentSession? session = null;

    if (_cfg.LastModel is not null &&
        availableModels.FirstOrDefault(m => m.Key == _cfg.LastModel) is { } lastModel)
    {
        var apiKey = ResolveApiKey(lastModel);
        if (apiKey is not null)
            session = CreateSession(lastModel, apiKey);
    }

    if (session is null && availableModels.Count > 0)
    {
        // Show model picker
        var picker = new TuiModelPicker();
        picker.SetModels(availableModels, _cfg.LastModel);
        var selected = await RunPickerAsync(shell, picker);
        if (selected is not null)
        {
            var apiKey = ResolveApiKey(selected);
            if (apiKey is null)
                apiKey = await PromptApiKeyAsync(selected.ProviderName, shell);
            if (apiKey is not null)
                session = CreateSession(selected, apiKey);
        }
    }

    if (session is null)
    {
        // No models available — show error in TUI and exit
        await ShowErrorAsync(shell, "No models available. Set an API key.");
        return;
    }

    // Run the main chat TUI
    using var app = new AppLayout(shell, session);
    await app.RunAsync();
}
```

### D6: Slash command bridge for TUI

**File:** `Omicron.CLI/Tui/TuiSlashCommandBridge.cs`

Wires the existing `SlashCommandDispatcher` into the TUI:
- `/help` → renders help text into transcript as system notice
- `/models` → shows model picker overlay
- `/model <n>` → switches model (ends current session, starts new one)
- `/fork` → forks current session
- `/resume` → shows session picker
- `/clear` → clears transcript store
- `/exit` → exits TUI cleanly

The bridge intercepts messages starting with `/` in `InputEditorWidget.OnSubmit`, executes the command, and suppresses normal session submission.

```csharp
public sealed class TuiSlashCommandBridge
{
    public bool TryHandle(string input, AppLayout app, out string? message);
}
```

### D7: Session cleanup on TUI exit

When the TUI exits (Ctrl+D, Escape, `/exit`):
1. Cancel any in-flight `PromptAsync`
2. Save session to disk via `JsonlSessionStore`
3. Exit alternate screen, show cursor, restore console mode
4. Print exit message: `"Session saved. Exiting Omicron TUI."`

## Risk Analysis

| Risk | Mitigation |
|------|-----------|
| Model picker blocks the render loop | Run picker as a modal overlay that owns the event loop temporarily |
| API key prompt needs secure input | Use `Console.ReadKey(intercept: true)` via the backend's raw mode |
| Session switch mid-conversation is jarring | Show a system notice: "Switched to {model}. Starting new session." |
| TUI exit without saving loses context | Always save on exit; add auto-save every 30 seconds |
